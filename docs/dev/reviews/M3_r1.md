# 验收卡 M3 · 第 1 轮

## AI 部分

### 怎么跑起来
解压 `claude-multi-launcher-v22-github-en.zip` 到稳定位置；双击 `create-desktop-shortcut.cmd` 重建 launcher 桌面图标，再从图标打开。也可直接双击 `Claude Multi Launcher.cmd`。状态：待验收。

### 3 分钟体验路线
1. 核对桌面图标 → 与你本机 Claude Desktop 的图标相同；档案图标可用“··· → 重建快捷方式”更新。
2. 按住最左侧圆点上下移动几行 → 松手后保存；关闭再打开仍保留顺序。
3. 拖动中按 Esc → 取消；圆点聚焦后按上下方向键 → 可一步移动。长列表拖到底部应自动滚动。
4. 点一行“··· → 删除记录”，先取消 → 列表不变；再确认 → 记录及本工具自己的快捷方式移除，所有数据目录保留。
5. 切换中文/英文、系统深浅色 → 名称括号、圆点和操作按钮显示正常，文字清晰。
