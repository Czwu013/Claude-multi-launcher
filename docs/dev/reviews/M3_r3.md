### 怎么跑起来
完整解压 claude-multi-launcher-v24-windows-x64.zip，关闭旧启动器，双击 claude-multi-launcher.exe。源码先 build-exe.cmd。需 WebView2 Runtime、.NET Framework 4.8、Windows x64；页脚 v24。运行 create-desktop-shortcut.cmd 重建启动器桌面入口。

### 3 分钟体验路线
1. 顶部无白条，标题栏和正文同色；拖动、边缘调整大小、最小化、最大化、还原及关闭符合预期。
2. EXE / 启动器桌面链接为原创灰色双窗口；README 首屏也有。启动时不打开 Edge/Chrome 浏览器窗口；msedgewebview2 渲染进程是预期行为。
3. 新建可丢弃 profile，桌面链接是本机 Claude 原图标；旧档案菜单“重建快捷方式”后也应恢复原图标。
4. 测试 profile 启动；关闭启动器后该 Claude 仍应运行。重新打开后目录/顺序不变。
5. 两实例的聚焦、正常关闭/独立强制取消、MCP 实际路径、版本更新修复及原回收站/隔离待验项继续按 M3_r2 / M1_r2 核对。
