1. 双击 cmd，再试桌面图标入口 → 网页界面打开；记录是否闪命令行窗口。

4. 启动 Claude 后关闭 launcher → Claude 继续运行，launcher 的 PowerShell 进程退出（不要结束其他 PowerShell）。
5. 仅用可丢弃的 test/test2 验证“连数据一起删除” → 先预览、运行中拦截、进回收站可还原；另记录大文件夹的 Windows 提示与行为。
