### 怎么跑起来
解压 `claude-multi-launcher-v23-github-en.zip` 到稳定位置，关闭旧启动器后双击 `Claude Multi Launcher.cmd`。页脚 v23。待验收，未代填用户结论。

### 3 分钟体验路线
1. 两个可丢弃档案依次启动 → 表格显示运行中；再次点“显示窗口” → 聚焦或明确提示去任务栏/托盘，不重复启动。
2. 新建一个测试档案 → 看到真实步骤；若快捷方式失败且记录已保存，刷新后只重建快捷方式。
3. Alpha 菜单“关闭此实例”先取消 → 无变化；再正常关闭 → 检查 Beta 仍在运行，状态刷新。
4. 如果仍驻留托盘 → 出现独立强制确认，先取消应保留；仅在可丢弃会话确认强制结束，检查另一个实例不受影响。
5. MCP 菜单 → 显示预期路径；不存在时不能打开；已有文件确认后用记事本打开，核对当前 Claude 实际使用的位置。
6. “检查与修复”先取消 → 不改动；再确认 → 查看逐项结果与桌面链接，外部同名快捷方式应保留。可在 Claude 更新后再复验。
7. 圆点拖动并重开、菜单删除取消及中英切换 → 原行为保留。关闭启动器后检查 Claude 继续运行、无残留 PowerShell。
